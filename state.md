## Useful Emerging Patterns

Encourage reusable phrases such as:
- "First, I'll check the data."
- "Then I segment the data to locate the impact."
- "If guardrails dip, we pause and investigate."
- "I ask clarifying questions early so the work stays on track."
- "I investigated and found that some events were not being sent."

These should be recycled in new contexts rather than memorized only as fixed scripts.
