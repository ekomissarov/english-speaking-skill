# English Speaking Skill

Небольшой переносимый набор инструкций и состояния обучения для практики разговорного английского с AI.

Цель проекта — сохранить не историю диалогов, а **сжатую модель того, как именно я изучаю английский**: цели, формат занятий, текущий уровень, слабые места и приоритеты.

Основной фокус сейчас:

- ~60% — подготовка к job interviews;
- ~40% — комфортная работа в англоязычной компании.

## Структура

Проект состоит из четырёх Markdown-файлов и разделён на три логических слоя.

### METHODOLOGY

`SKILL.md`

Описывает, **как AI должен проводить занятия**:

- Real-time Speaking;
- Prepared Speaking;
- Grammar Drills;
- Retelling;
- Progress Assessment;
- правила исправления ошибок;
- spaced repetition;
- постепенное увеличение сложности;
- перенос слабых мест между разными форматами практики.

### LEARNER

`learner.md`

Относительно стабильный профиль ученика:

- цели;
- профессиональный контекст;
- предпочтительный стиль занятий;
- требования к обратной связи;
- основные speaking priorities.

`curriculum.md`

Карта того, **что именно нужно практиковать**:

- рабочие и интервью-сценарии;
- темы для Prepared Speaking;
- grammar topics;
- retelling;
- направления развития разговорной речи.

### STATE

`state.md`

Текущее состояние обучения:

- текущая примерная CEFR-оценка;
- слабые места;
- сильные стороны;
- recurring errors;
- grammar priorities;
- недавно отрабатывавшиеся конструкции;
- ближайшие приоритеты.

Это самый динамичный файл проекта.

## Основные режимы практики

### Real-time Speaking

Спонтанная речь без подготовки.

Основная цель — уменьшить паузы, научиться быстрее строить предложения и сохранять грамматическую стабильность под давлением.

### Prepared Speaking

Ответы после небольшой подготовки.

Используется для тренировки:

- interview answers;
- объяснения аналитических решений;
- рабочих обсуждений;
- status updates;
- аргументации;
- уточнений и несогласия с коллегами.

Слабые места, обнаруженные в Real-time Speaking, должны периодически возвращаться здесь в новом контексте.

### Grammar Drills

Короткие упражнения по одному вопросу за раз.

Темы выбираются не строго по порядку учебника, а с повышенным весом для:

1. повторяющихся ошибок;
2. слабых тем;
3. часто используемой разговорной грамматики;
4. business English;
5. spaced repetition.

В качестве широкой карты используется *English Grammar in Use* Raymond Murphy.

### Retelling

Тренировка удержания контекста и воспроизведения смысла своими словами.

Основная схема:

**Chunk → Keywords → Retell**

Начальная длина фрагментов — примерно 20–30 секунд с постепенным увеличением сложности.

## Progress Assessment

Прогресс оценивается отдельно по четырём направлениям:

1. Real-time Speaking
2. Prepared Speaking
3. Grammar Drills
4. Retelling

Используется условная шкала:

**B1 → B1+ → B2- → B2 → B2+**

Оценка должна быть консервативной и учитывать не только знание правил, но и способность использовать английский в реальной речи.

## Главная цель

Не просто успешно проходить интервью, а постепенно прийти к состоянию, когда можно **комфортно работать в англоязычной компании**:

- участвовать во встречах;
- объяснять аналитику;
- задавать уточняющие вопросы;
- обсуждать гипотезы;
- аргументировать решения;
- не соглашаться и уточнять;
- делать короткие рабочие апдейты;
- поддерживать обычное профессиональное общение.

При этом в текущий момент job interview остаётся главным практическим приоритетом.

## Как использовать

Можно передать эти файлы AI-системе как контекст или использовать `SKILL.md` как основную инструкцию, а остальные файлы — как дополнительные данные о learner и его текущем состоянии.

При переносе в новый AI-контекст важно передать все четыре файла.

Проект не является полной копией истории обучения. Это **сжатое переносимое состояние системы обучения**:

> methodology + learner profile + curriculum + current state
