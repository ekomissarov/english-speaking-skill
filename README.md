# English Speaking Skill

Персональная система для долгосрочного изучения и практики английского языка с ChatGPT.

Репозиторий разделяет **методику обучения**, **профиль ученика**, **учебную программу** и **текущее состояние обучения**, чтобы у каждого типа информации было одно основное место хранения — single source of truth.

## Архитектура

Система состоит из четырёх основных файлов:

```text
english-speaking-skill/
├── README.md
├── SKILL.md
├── learner.md
├── curriculum.md
└── state.md
```

### `SKILL.md` — методика обучения

Определяет, **как ChatGPT должен проводить обучение**.

Здесь находятся основные принципы работы: как проводить занятия, как исправлять ошибки, как организовывать разные режимы практики, как переносить изученный материал в разговорную речь и как оценивать прогресс.

Этот файл описывает методику и не должен использоваться для хранения текущего прогресса ученика.

### `learner.md` — профиль ученика

Содержит относительно стабильную информацию об ученике, которая влияет на обучение.

Здесь хранятся долгосрочные цели, профессиональный контекст, предпочтения в обучении и другая информация, которая меняется сравнительно редко.

Этот файл не предназначен для отслеживания ежедневного прогресса.

### `curriculum.md` — карта обучения

Определяет, **что необходимо изучать и практиковать**.

Здесь описывается структура программы и области английского языка, которые должны постепенно охватываться в процессе обучения.

`curriculum.md` описывает пространство обучения, но не текущее положение ученика внутри него.

### `state.md` — текущее состояние

Определяет, **где ученик находится сейчас**.

Это динамическая часть системы. Здесь отслеживаются текущие оценки уровня, слабые и сильные стороны, приоритеты, недавний прогресс, темы для интервального повторения и детальный прогресс по структурированным учебным материалам.

В отличие от остальных файлов, `state.md` должен обновляться регулярно.

## Разделение ответственности

Каждый тип информации должен иметь одно каноническое место хранения.

| Вопрос | Источник |
|---|---|
| Как проводить обучение? | `SKILL.md` |
| Кто ученик и каковы его долгосрочные цели и предпочтения? | `learner.md` |
| Что необходимо изучать? | `curriculum.md` |
| Каков текущий уровень, прогресс и приоритеты? | `state.md` |

Информация не должна без необходимости копироваться между файлами.

В частности, `README.md` **не должен пересказывать текущее содержимое учебной программы, профиль ученика или состояние обучения**. Его задача — объяснять концепцию и архитектуру системы.

## Состояние и прогресс

Система рассматривает состояние обучения как накопительный и сохраняемый контекст.

Когда во время практики появляются новые данные о знаниях ученика, соответствующий прогресс должен отражаться в `state.md`.

Полезная историческая информация не должна удаляться только ради сокращения файла, если она помогает принимать дальнейшие решения об обучении.

Оценивать прогресс следует консервативно. Один правильный ответ ещё не означает освоение темы. Более сильным свидетельством является успешное использование материала несколько раз, в разные дни и в разных контекстах.

## Цикл обучения

Архитектура поддерживает непрерывный цикл:

```text
Практика
   ↓
Выявление сильных и слабых мест
   ↓
Целевая отработка
   ↓
Перенос в менее контролируемую речь
   ↓
Повторная оценка
   ↓
Обновление состояния
   ↺
```

Цель системы — не просто успешно выполнять упражнения.

Изученный материал должен постепенно переходить из контролируемой практики в автоматическое использование в спонтанной английской речи.

## Принцип обновления

При изменении системы:

1. Изменения методики вносятся в `SKILL.md`.
2. Изменения стабильной информации об ученике — в `learner.md`.
3. Изменения структуры и содержания программы обучения — в `curriculum.md`.
4. Изменения текущего прогресса, уровня и приоритетов — в `state.md`.
5. `README.md` изменяется только тогда, когда меняется **концепция или архитектура системы**.

Такое разделение позволяет избежать дублирования информации и проблем с синхронизацией между файлами.
